# Experiment 1: Designing UI Using Bootstrap Components

## Objective
To design and implement a responsive user interface using the Bootstrap component library within a Single Page Application.

---

## Overview
Bootstrap is a widely used front-end framework that provides pre-built, reusable UI components and a responsive grid system.  
This experiment demonstrates how Bootstrap can be integrated into a React application to rapidly develop consistent and mobile-friendly user interfaces.

---

## Software Requirements
- Node.js (v14 or above)
- React.js
- Bootstrap 5
- Web Browser (Chrome/Edge/Firefox)
- Code Editor (VS Code recommended)

<img width="1160" height="803" alt="Screenshot 2026-01-28 094936" src="https://github.com/user-attachments/assets/80f1926a-c822-4382-8748-92bbbda0c20d" />

## Installation

### 1. Create React Application
```bash
npx create-react-app bootstrap-ui
cd bootstrap-ui

2. Install Bootstrap
npm install bootstrap

3.Import Bootstrap CSS
import 'bootstrap/dist/css/bootstrap.min.css';

4.Run the Application
npm start
```

## Conclusion
Bootstrap simplifies UI development by providing reusable components and a responsive grid system, significantly reducing development time while maintaining design consistency.

# Experiment 3: Form Design Using Material UI

## Objective
To design and implement a modern, responsive form interface using the Material UI (MUI) component library in a React application.

## Overview
Material UI (MUI) is a popular React component library that follows Google’s Material Design principles.  
It provides pre-built, customizable components that enable developers to build clean, professional, and accessible user interfaces efficiently.

This experiment demonstrates the creation of a simple form with input fields and buttons using MUI components.

## Software Requirements
- Node.js (v14 or above)
- React.js
- Material UI (MUI)
- Web Browser (Chrome/Edge/Firefox)
- Code Editor (VS Code recommended)

### 1
```bash
npx create-react-app material-ui-form
cd material-ui-form

Install Material UI
```

## Implementation
Components Used
Container / Box
Paper (Card layout)

Material Design based UI
