# Experiment 1: Designing UI Using Bootstrap Components

## Objective
To design and implement a responsive user interface using the Bootstrap component library within a Single Page Application.

---

## Overview
Bootstrap is a widely used front-end framework that provides pre-built, reusable UI components and a responsive grid system.  
This experiment demonstrates how Bootstrap can be integrated into a React application to rapidly develop consistent and mobile-friendly user interfaces.

---

## Software Requirements
- Node.js (v14 or above)
- React.js
- Bootstrap 5
- Web Browser (Chrome/Edge/Firefox)
- Code Editor (VS Code recommended)

## Installation

### 1. Create React Application
```bash
npx create-react-app bootstrap-ui
cd bootstrap-ui

2. Install Bootstrap
npm install bootstrap

3.Import Bootstrap CSS
import 'bootstrap/dist/css/bootstrap.min.css';

4.Run the Application
npm start
```

## Conclusion
Bootstrap simplifies UI development by providing reusable components and a responsive grid system, significantly reducing development time while maintaining design consistency.
